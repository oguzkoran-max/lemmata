## Prompt Summary

README and the project website state that Lemmata supports five languages, but the v0.3.0 changes (P045–P052) had been exercised only on Italian texts (Decameron, Svevo). Before the release Claude proposed a technical check of German, French and Spanish: does the app run end to end, are words reduced to lemmas, are stopwords removed, do the result tabs open. The first author asked whether this would cause a problem for the article in preparation; Claude answered that it would not, provided it is reported as a technical check and not as a validation of these languages. The first author then approved it.

## Full Prompt

```
makalemiz açısından bir sorun olacak mı? olmayacaksa evet dene
```

(Turkish-language session, 19 Nov 2026. Translation: "Will it cause a problem for our article? If not, yes, try it.")

## Response Summary

- Inputs: four short texts per language (271 to 288 words per language), written by Claude for this check on everyday themes (town, sea, family, war). They are not literary corpora and carry no finding. Texts, scripts and results are kept outside the repository with the project records.
- The spaCy models de/fr/es_core_news_sm 3.8.0 were already installed in the project environment.
- Script check (`process_documents`, `build_dtm`, `run_lda` with both methods, `compute_coherence`), default settings, 2 topics.
- App check: each language selected in the sidebar, the four files uploaded, Run Analysis, all seven tabs opened.

## Results

- All three languages ran end to end with both inference methods; no exception or error message in any of the seven tabs.
- No word on spaCy's stoplist of the language reached the model.
- Ten hand-picked inflected nouns and adjectives per language (not a measure of lemmatisation accuracy):
  - German 10/10. Lemmas are lowercased, as for every language (`token.lemma_.lower()`), so "Häuser" becomes "haus".
  - French 10/10. "yeux" becomes "oeil", without the œ ligature.
  - Spanish 9/10. "largas" becomes "larga", not "largo".
- Language-mismatch warning: the early check (`check_language_match`) flags German and French texts run with Italian selected, but not Spanish text: it counts stopwords in the first 500 characters, and Italian and Spanish share short function words ("a", "del", "la", "le", "pero", "se"), so the share (0.106) stays just above the threshold (0.10). A follow-up check showed that in the app none of the three mismatches produced a warning after a successful run: the early check is shown only when the analysis fails, and the check after preprocessing (kept lemmas over tokens below 0.10) did not fire (0.41 to 0.71). Fixed in P054.

## Decision

None. No code was changed. The results do not validate German, French or Spanish; the only language-level measurement remains the Italian lemmatisation check (L1).
