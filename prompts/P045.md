## Prompt Summary
Unlike P001–P042, this change did not start from a single English prompt. The first author and Claude Code agreed a written plan in a Turkish-language session after a validation study (reproduction of Cooper et al. 2021, *Decameron*, under a protocol fixed before any run). The study found:
1. The convergence warning (decision 124) appeared on all 73 Lemmata runs, including models that had converged by scikit-learn's own criterion (check K3).
2. The preprocessing summary subtracted tokens on both stopword lists twice (`preprocessing.py`, `total_after_stopwords`).
3. With its defaults, Lemmata did not recover the published findings that MALLET recovered in 7–8 of 10 runs; the difference arose in the model layer (variational Bayes), not in preprocessing.

The plan: fix (1) and (2); add collapsed Gibbs sampling (tomotopy) with MALLET's own defaults, fixed before any new validation run, as the default method; keep the variational method as an option; raise the topic limit to 30; keep historical records (ARCHITECTURE.md, P001–P044 logs) unchanged.

## Result
- Gibbs sampling via `GibbsLDA` (tomotopy 0.14.0), exposing the scikit-learn attributes the pipeline uses. Same seed gives the same model (one worker).
- Convergence: variational fits check perplexity every 10 iterations (`evaluate_every=10`, `perp_tol=0.1`); Gibbs fits compare mean log-likelihood per word over the last two 50-iteration windows (relative change ≤ 0.1%). A test reproduces K3: a converged model no longer warns.
- Stopwords on both lists are counted once; the overlap is shown.
- The Topic Map had always fallen back to the PCA chart (pyLDAvis 3.4 removed `pyLDAvis.sklearn`; PCoA fails with numpy 2). It now uses `pyLDAvis.prepare` with metric MDS and the topic list's numbering.
- Version 0.3.0 in code and pyproject (the v0.2.0 tag existed while the code still said 0.1.0).
- Svevo trilogy (examples/), Mac with Apple silicon: Gibbs model fit 0.6 s (k=5) and 0.9 s (k=20) on 71,357 lemmas.
- Not yet done: README wording on expert review and testing (awaits the authors' approval), CITATION.cff and release tag, deployment, new validation runs.
